# 🏥 MediFlow

MediFlow is a full-stack healthcare management platform designed to connect patients, doctors, and administrators in one secure system.

## Features

- Patient and doctor authentication
- Role-based access control
- Appointment management
- Doctor availability
- Medical records
- Digital prescriptions
- Medical document management
- Notifications
- Admin dashboard
- Healthcare analytics

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma ORM
